# 10. 다양한 그래프 알고리즘

## 1. 그래프의 기본 개념

그래프는 코딩 테스트에서 자주 만나게 될 중요한 자료구조입니다. 그래프는 **정점(노드)**과 이들을 연결하는 **간선(엣지)**으로 구성됩니다. 실생활에서 도로망, 소셜 네트워크, 컴퓨터 네트워크 등 다양한 곳에서 그래프 구조를 볼 수 있습니다.

### 그래프의 주요 종류:

1. **DFS (깊이 우선 탐색)**: 한 경로를 끝까지 탐색한 후 다른 경로를 탐색하는 방식
2. **BFS (너비 우선 탐색)**: 현재 위치에서 가까운 노드부터 탐색하는 방식
3. **최단 경로 알고리즘**: 두 노드 사이의 가장 짧은 경로를 찾는 알고리즘 (다익스트라, 플로이드-워셜 등)
4. **위상 정렬**: 방향 그래프에서 순서가 있는 작업을 순서대로 나열하는 알고리즘
5. **최소 신장 트리**: 모든 노드를 최소 비용으로 연결하는 트리 (크루스칼, 프림 알고리즘)

### 그래프 표현 방법:

그래프를 코드로 표현하는 방법에는 두 가지가 있습니다:

1. **인접 행렬 (Adjacency Matrix)**:
   - 2차원 배열을 사용하여 그래프를 표현
   - 노드 간 연결 여부를 바로 확인할 수 있어 빠름
   - 메모리를 많이 사용함 (노드 수가 V일 때 O(V²) 메모리 필요)

```python
# 인접 행렬 예시 (노드 1,2,3,4,5가 있는 경우)
graph = [
    [0, 0, 0, 0, 0, 0],  # 0번 인덱스는 사용하지 않음
    [0, 0, 1, 1, 0, 0],  # 노드 1은 노드 2, 3과 연결됨
    [0, 1, 0, 0, 1, 0],  # 노드 2는 노드 1, 4와 연결됨
    [0, 1, 0, 0, 1, 1],  # 노드 3은 노드 1, 4, 5와 연결됨
    [0, 0, 1, 1, 0, 0],  # 노드 4는 노드 2, 3과 연결됨
    [0, 0, 0, 1, 0, 0]   # 노드 5는 노드 3과 연결됨
]
```

2. **인접 리스트 (Adjacency List)**:
   - 각 노드마다 연결된 노드를 리스트로 저장
   - 메모리를 효율적으로 사용함 (간선 수가 E일 때 O(E) 메모리 필요)
   - 특정 노드 간 연결 확인은 상대적으로 느림

```python
# 인접 리스트 예시
graph = [
    [],             # 0번 인덱스는 사용하지 않음
    [2, 3],         # 노드 1은 노드 2, 3과 연결됨
    [1, 4],         # 노드 2는 노드 1, 4와 연결됨
    [1, 4, 5],      # 노드 3은 노드 1, 4, 5와 연결됨
    [2, 3],         # 노드 4는 노드 2, 3과 연결됨
    [3]             # 노드 5는 노드 3과 연결됨
]
```

어떤 방법을 선택할지는 문제 상황에 따라 다릅니다:
- 노드 수가 적고 간선이 많은 그래프: **인접 행렬**
- 노드 수가 많고 간선이 적은 그래프: **인접 리스트**

## 2. 서로소 집합(Disjoint Sets) 알고리즘

서로소 집합은 공통 원소가 없는 두 집합을 의미합니다. 이 알고리즘은 여러 개의 노드가 존재할 때, 각 노드가 속한 집합을 관리하는 자료구조입니다.

### 서로소 집합의 핵심 연산:

1. **union(합집합)**: 두 노드가 속한 집합을 하나로 합치는 연산
2. **find(찾기)**: 특정 노드가 어떤 집합에 속해 있는지 찾는 연산

### 서로소 집합 알고리즘의 기본 구조:

1. 초기에는 모든 노드가 자기 자신만 포함하는 집합에 속함
2. `union` 연산을 통해 두 노드를 같은 집합에 포함시킴
3. `find` 연산으로 두 노드가 같은 집합에 속하는지 확인

### 기본적인 서로소 집합 구현:

```python
# 특정 원소가 속한 집합 찾기
def find_parent(parent, x):
    # 루트 노드를 찾을 때까지 재귀 호출
    if parent[x] != x:
        return find_parent(parent, parent[x])
    return parent[x]

# 두 원소가 속한 집합 합치기
def union_parent(parent, a, b):
    a = find_parent(parent, a)
    b = find_parent(parent, b)
    if a < b:
        parent[b] = a
    else:
        parent[a] = b

# 노드 개수와 간선(union 연산) 개수 입력
v, e = map(int, input().split())
parent = [0] * (v + 1)  # 부모 테이블 초기화

# 부모를 자기 자신으로 초기화
for i in range(1, v + 1):
    parent[i] = i

# union 연산 수행
for i in range(e):
    a, b = map(int, input().split())
    union_parent(parent, a, b)

# 각 원소가 속한 집합 출력
print('각 원소가 속한 집합: ', end='')
for i in range(1, v + 1):
    print(find_parent(parent, i), end=' ')

print()

# 부모 테이블 출력
print('부모 테이블: ', end='')
for i in range(1, v + 1):
    print(parent[i], end=' ')
```

### 서로소 집합 최적화 - 경로 압축:

위 코드는 트리가 길어지면 `find` 연산이 비효율적이 될 수 있습니다. 이를 최적화하는 방법이 **경로 압축(Path Compression)**입니다.

```python
# 경로 압축 기법을 적용한 find 함수
def find_parent(parent, x):
    if parent[x] != x:
        parent[x] = find_parent(parent, parent[x])
    return parent[x]
```

이렇게 하면 `find` 함수를 호출할 때 해당 노드에서 루트 노드까지의 모든 노드의 부모가 루트 노드로 바로 설정되어 시간 복잡도가 크게 향상됩니다.

### 경로 압축의 효과:

예를 들어 노드가 1, 2, 3, 4, 5로 있고, 다음과 같은 순서로 `union` 연산을 수행했다고 가정해봅시다:
1. `union(1, 2)` - 노드 1과 2를 합침
2. `union(2, 3)` - 노드 2와 3을 합침
3. `union(3, 4)` - 노드 3과 4를 합침
4. `union(4, 5)` - 노드 4와 5를 합침

이 경우 트리 구조가 길어져서 노드 5의 루트를 찾을 때 5 → 4 → 3 → 2 → 1 순서로 거슬러 올라가야 합니다. 하지만 경로 압축을 적용하면 `find(5)`를 호출한 후에는 노드 5의 부모가 바로 노드 1로 설정되어 다음에 `find(5)`를 호출할 때는 바로 루트 노드를 찾을 수 있습니다.

## 서로소 집합을 이용한 사이클 판별

서로소 집합 알고리즘은 **무방향 그래프**에서 사이클 발생 여부를 판별하는 데 사용될 수 있습니다.

### 사이클 판별 알고리즘:

1. 모든 간선을 하나씩 확인하며 두 노드의 루트 노드를 찾음
2. 루트 노드가 서로 다르면 두 노드를 `union` 함
3. 루트 노드가 서로 같으면 사이클이 발생한 것

```python
# 경로 압축 기법을 적용한 find 함수
def find_parent(parent, x):
    if parent[x] != x:
        parent[x] = find_parent(parent, parent[x])
    return parent[x]

# 두 원소가 속한 집합 합치기
def union_parent(parent, a, b):
    a = find_parent(parent, a)
    b = find_parent(parent, b)
    if a < b:
        parent[b] = a
    else:
        parent[a] = b

# 노드 개수와 간선 개수 입력
v, e = map(int, input().split())
parent = [0] * (v + 1)  # 부모 테이블 초기화

# 부모를 자기 자신으로 초기화
for i in range(1, v + 1):
    parent[i] = i

cycle = False  # 사이클 발생 여부

for i in range(e):
    a, b = map(int, input().split())
    # 사이클이 발생한 경우 종료
    if find_parent(parent, a) == find_parent(parent, b):
        cycle = True
        break
    # 사이클이 발생하지 않았다면 union 수행
    else:
        union_parent(parent, a, b)

if cycle:
    print("사이클이 발생했습니다.")
else:
    print("사이클이 발생하지 않았습니다.")
```

### 사이클 판별 예시:

삼각형 모양의 그래프(노드 1, 2, 3이 서로 연결됨)에서 사이클 판별 과정:

1. 간선 (1, 2) 확인: 루트 노드가 다르므로 `union` 수행
2. 간선 (1, 3) 확인: 루트 노드가 다르므로 `union` 수행
3. 간선 (2, 3) 확인: 이미 두 노드의 루트 노드가 같음 → 사이클 발생!


# 3. 최소 신장 트리와 크루스칼 알고리즘

## 신장 트리(Spanning Tree)란?

신장 트리는 그래프에서 **모든 노드를 포함하면서 사이클이 존재하지 않는 부분 그래프**입니다. 코딩 테스트에서 자주 출제되는 문제 유형 중 하나입니다.

신장 트리의 특징:
- 모든 노드를 포함함
- 모든 노드가 서로 연결됨
- 사이클이 없음 (트리의 특성)

하나의 그래프에서는 여러 개의 신장 트리가 존재할 수 있습니다. 예를 들어 노드가 많고 간선이 많은 복잡한 그래프에서도 여러 가지 방법으로 모든 노드를 연결하는 트리를 구성할 수 있습니다.

## 최소 신장 트리(Minimum Spanning Tree)

최소 신장 트리는 **간선의 가중치 합이 최소가 되는 신장 트리**를 말합니다.

실생활에서의 예시:
- 도시를 연결하는 도로 네트워크에서 최소 비용으로 모든 도시를 연결하는 방법
- 통신 네트워크에서 최소 비용으로 모든 장치를 연결하는 방법

여러 신장 트리 중에서 간선의 가중치 합이 가장 작은 신장 트리를 찾는 것이 핵심입니다.

## 크루스칼 알고리즘(Kruskal Algorithm)

크루스칼 알고리즘은 최소 신장 트리를 찾는 대표적인 알고리즘입니다. 이 알고리즘은 **그리디 알고리즘**으로 분류되며, 항상 가장 가중치가 작은 간선부터 선택하는 방식으로 동작합니다.

### 크루스칼 알고리즘의 동작 과정:

1. 모든 간선을 가중치에 따라 오름차순으로 정렬합니다.
2. 가장 가중치가 작은 간선부터 선택합니다.
3. 선택한 간선이 사이클을 만들지 않는 경우에만 최소 신장 트리에 포함시킵니다.
4. 위 과정을 반복하여 간선의 개수가 '노드 개수 - 1'이 될 때까지 진행합니다.

### 크루스칼 알고리즘 예시:

다음과 같은 그래프가 있다고 가정해봅시다:
- 노드 7개와 간선 9개로 구성된 그래프
- 간선의 가중치는 다음과 같습니다:

| 간선 | (1, 2) | (1, 5) | (2, 3) | (2, 6) | (3, 4) | (4, 6) | (4, 7) | (5, 6) | (6, 7) |
|-----|-------|-------|-------|-------|-------|-------|-------|-------|-------|
| 비용 | 29    | 75    | 35    | 34    | 7     | 23    | 13    | 53    | 25    |

**Step 1:** 가장 가중치가 작은 간선 (3, 4)를 선택합니다. 비용은 7입니다.

**Step 2:** 다음으로 작은 가중치의 간선 (4, 7)을 선택합니다. 비용은 13입니다.

**Step 3:** 다음으로 작은 가중치의 간선 (4, 6)을 선택합니다. 비용은 23입니다.

**Step 4:** 다음으로 작은 가중치의 간선 (6, 7)을 확인합니다. 하지만 이 간선을 추가하면 사이클이 형성되므로 선택하지 않습니다.

**Step 5:** 다음으로 작은 가중치의 간선 (1, 2)를 선택합니다. 비용은 29입니다.

**Step 6:** 다음으로 작은 가중치의 간선 (2, 6)을 선택합니다. 비용은 34입니다.

**Step 7:** 다음으로 작은 가중치의 간선 (2, 3)을 확인합니다. 하지만 이 간선을 추가하면 사이클이 형성되므로 선택하지 않습니다.

**Step 8:** 다음으로 작은 가중치의 간선 (5, 6)을 선택합니다. 비용은 53입니다.

**Step 9:** 다음으로 작은 가중치의 간선 (1, 5)를 확인합니다. 하지만 이 간선을 추가하면 사이클이 형성되므로 선택하지 않습니다.

최종적으로 선택된 간선은 (3, 4), (4, 7), (4, 6), (1, 2), (2, 6), (5, 6)이며, 총 비용은 7 + 13 + 23 + 29 + 34 + 53 = 159입니다.

## 크루스칼 알고리즘 구현

크루스칼 알고리즘은 서로소 집합(Disjoint Set) 자료구조를 활용하여 구현합니다. 이를 통해 간선이 사이클을 형성하는지 효율적으로 확인할 수 있습니다.

### 파이썬으로 구현한 크루스칼 알고리즘:

```python
# 특정 원소가 속한 집합을 찾기
def find_parent(parent, x):
    # 루트 노드가 아니라면, 루트 노드를 찾을 때까지 재귀적으로 호출
    if parent[x] != x:
        parent[x] = find_parent(parent, parent[x])
    return parent[x]

# 두 원소가 속한 집합을 합치기
def union_parent(parent, a, b):
    a = find_parent(parent, a)
    b = find_parent(parent, b)
    if a < b:
        parent[b] = a
    else:
        parent[a] = b

# 노드의 개수와 간선(union 연산)의 개수 입력받기
v, e = map(int, input().split())
parent = [0] * (v + 1)  # 부모 테이블 초기화

# 모든 간선을 담을 리스트와 최종 비용을 담을 변수
edges = []
result = 0

# 부모 테이블상에서, 부모를 자기 자신으로 초기화
for i in range(1, v + 1):
    parent[i] = i

# 모든 간선에 대한 정보를 입력받기
for _ in range(e):
    a, b, cost = map(int, input().split())
    # 비용순으로 정렬하기 위해서 튜플의 첫 번째 원소를 비용으로 설정
    edges.append((cost, a, b))

# 간선을 비용순으로 정렬
edges.sort()

# 간선을 하나씩 확인하며
for edge in edges:
    cost, a, b = edge
    # 사이클이 발생하지 않는 경우에만 집합에 포함
    if find_parent(parent, a) != find_parent(parent, b):
        union_parent(parent, a, b)
        result += cost

print(result)  # 최소 신장 트리의 총 비용 출력
```

### 코드 설명:

1. `find_parent` 함수는 특정 노드가 속한 집합(루트 노드)을 찾는 함수로, 경로 압축 기법을 적용하여 효율성을 높였습니다.
2. `union_parent` 함수는 두 노드가 속한 집합을 합치는 함수입니다.
3. 모든 간선을 비용 순으로 정렬한 후, 가장 비용이 작은 간선부터 선택합니다.
4. 선택한 간선이 사이클을 발생시키지 않는 경우에만 최소 신장 트리에 포함시킵니다.
5. 이 과정을 반복하여 최소 신장 트리를 완성합니다.

### 크루스칼 알고리즘 사용 예시:

```
입력 예시:

1 2 29
1 5 75
2 3 35
2 6 34
3 4 7
4 6 23
4 7 13
5 6 53
6 7 25

출력 예시:

```

## 크루스칼 알고리즘의 시간 복잡도

크루스칼 알고리즘의 시간 복잡도는 **O(ElogE)**입니다. 여기서 E는 간선의 개수입니다.

시간 복잡도가 이렇게 결정되는 이유는 알고리즘에서 가장 많은 시간이 소요되는 부분이 **간선을 정렬하는 작업**이기 때문입니다. E개의 간선을 정렬하는 데 일반적으로 O(ElogE)의 시간이 필요합니다.

크루스칼 알고리즘 내부에서 사용되는 서로소 집합(Union-Find) 연산은 경로 압축 기법을 적용하면 거의 상수 시간에 가깝게 동작하므로, 정렬 시간보다 작아 무시할 수 있습니다.

## 크루스칼 알고리즘의 활용

크루스칼 알고리즘은 다음과 같은 상황에서 활용할 수 있습니다:

1. **네트워크 구축**: 여러 지점을 연결하는 네트워크 케이블을 최소 비용으로 설치하는 문제
2. **도로 건설**: 여러 도시를 연결하는 도로를 최소 비용으로 건설하는 문제
3. **파이프라인 설계**: 여러 지점을 연결하는 파이프라인을 최소 비용으로 설치하는 문제

특히 크루스칼 알고리즘은 간선의 개수가 적은 **희소 그래프(Sparse Graph)**에서 효율적으로 동작합니다. 반면, 간선의 개수가 많은 밀집 그래프(Dense Graph)에서는 프림(Prim) 알고리즘이 더 효율적일 수 있습니다.

## 최소 신장 트리와 크루스칼 알고리즘 정리

최소 신장 트리와 크루스칼 알고리즘은 그래프 이론에서 중요한 개념으로, 최소 비용으로 모든 노드를 연결하는 문제를 해결하는 데 유용합니다. 특히 크루스칼 알고리즘은 간단하면서도 효율적인 방법으로 최소 신장 트리를 찾을 수 있어 실제 문제 해결에 많이 활용됩니다.

크루스칼 알고리즘의 핵심은:
1. 간선을 가중치 순으로 정렬하기
2. 가장 가중치가 작은 간선부터 선택하기
3. 사이클을 형성하는 간선 제외하기
4. 최종적으로 '노드 개수 - 1'개의 간선을 선택하기

# 4. 위상 정렬(Topology Sort)

## 위상 정렬의 개념

위상 정렬은 정렬 알고리즘의 일종으로, **순서가 정해져 있는 일련의 작업을 차례대로 수행**해야 할 때 사용하는 알고리즘입니다. 쉽게 말해, 방향이 있는 그래프에서 사이클이 없는 그래프(DAG, Directed Acyclic Graph)의 모든 노드를 '방향성에 거스르지 않도록' 순서대로 나열하는 것입니다.

위상 정렬을 이해하는 가장 쉬운 방법은 대학 수업의 선수과목 체계를 생각해보는 것입니다:
- '자료구조' 과목을 먼저 수강해야 '알고리즘' 과목을 들을 수 있음
- '프로그래밍 기초'를 들어야 '자료구조'를 들을 수 있음
- 이런 선후관계를 모두 고려해서 학생이 들어야 할 과목 순서를 정하는 것

## 위상 정렬의 활용 분야

위상 정렬 알고리즘은 다음과 같은 상황에서 자주 사용됩니다:

1. **선수 과목 고려한 학습 순서 설정**: 대학 커리큘럼 설계
2. **프로젝트 일정 관리**: 작업 간의 의존성이 있는 프로젝트 스케줄링
3. **프로그램 빌드 순서 관리**: 라이브러리나 모듈 간의 의존 관계를 고려한 빌드 순서
4. **논문 참조 관계 분석**: 어떤 논문이 다른 논문을 인용하는 관계를 분석할 때

## 위상 정렬 알고리즘의 동작 원리

위상 정렬 알고리즘은 다음 단계로 진행됩니다:

1. **진입차수 계산**: 각 노드의 진입차수(다른 노드에서 해당 노드로 들어오는 간선의 수)를 계산합니다.
2. **시작점 찾기**: 진입차수가 0인 노드(선행 작업이 없는 노드)를 큐에 넣습니다.
3. **반복 처리**:
   - 큐에서 노드를 하나 꺼내어 결과 리스트에 추가합니다.
   - 해당 노드에서 출발하는 모든 간선을 제거합니다.
   - 간선 제거로 인해 진입차수가 0이 된 노드를 큐에 추가합니다.
   - 큐가 빌 때까지 반복합니다.

### 단계별 실행 과정 예시

예를 들어 다음과 같은 그래프가 있다고 가정해봅시다:
- 노드 1은 노드 2와 노드 5로 향하는 간선이 있음
- 노드 2는 노드 3과 노드 4로 향하는 간선이 있음
- 노드 3은 노드 6으로 향하는 간선이 있음
- 노드 4는 노드 3과 노드 6으로 향하는 간선이 있음
- 노드 5는 노드 3으로 향하는 간선이 있음

#### 초기 상태
- 진입차수: [0, 0, 1, 2, 1, 1, 2]
  (0번 노드는 사용하지 않음. 인덱스 1부터 6까지의 노드 진입차수)
- 진입차수가 0인 노드는 노드 1뿐이므로, 큐에 노드 1을 넣습니다.

#### 1단계: 노드 1 처리
- 노드 1을 큐에서 꺼내고 결과 리스트에 추가합니다: [1]
- 노드 1에서 나가는 간선(1→2, 1→5)을 제거합니다.
- 노드 2와 노드 5의 진입차수가 0이 되어 큐에 추가합니다.
- 현재 큐: [2, 5]

#### 2단계: 노드 2 처리
- 노드 2를 큐에서 꺼내고 결과 리스트에 추가합니다: [1, 2]
- 노드 2에서 나가는 간선(2→3, 2→4)을 제거합니다.
- 노드 4의 진입차수가 0이 되어 큐에 추가합니다.
- 현재 큐: [5, 4]

#### 3단계: 노드 5 처리
- 노드 5를 큐에서 꺼내고 결과 리스트에 추가합니다: [1, 2, 5]
- 노드 5에서 나가는 간선(5→3)을 제거합니다.
- 노드 3의 진입차수가 0이 되어 큐에 추가합니다.
- 현재 큐: [4, 3]

#### 4단계: 노드 4 처리
- 노드 4를 큐에서 꺼내고 결과 리스트에 추가합니다: [1, 2, 5, 4]
- 노드 4에서 나가는 간선(4→3, 4→6)을 제거합니다.
- 노드 3은 이미 큐에 있으므로 중복 추가하지 않습니다.
- 현재 큐: [3]

#### 5단계: 노드 3 처리
- 노드 3을 큐에서 꺼내고 결과 리스트에 추가합니다: [1, 2, 5, 4, 3]
- 노드 3에서 나가는 간선(3→6)을 제거합니다.
- 노드 6의 진입차수가 0이 되어 큐에 추가합니다.
- 현재 큐: [6]

#### 6단계: 노드 6 처리
- 노드 6을 큐에서 꺼내고 결과 리스트에 추가합니다: [1, 2, 5, 4, 3, 6]
- 노드 6에서 나가는 간선이 없으므로 아무 것도 제거하지 않습니다.
- 큐가 비었으므로 알고리즘이 종료됩니다.

최종 위상 정렬 결과: [1, 2, 5, 4, 3, 6]

## 위상 정렬의 특징

위상 정렬에는 몇 가지 중요한 특징이 있습니다:

1. **결과의 다양성**: 위상 정렬의 결과는 유일하지 않을 수 있습니다. 예를 들어, 위 예시에서 노드 2와 노드 5는 서로 독립적이므로 [1, 2, 5, 4, 3, 6] 또는 [1, 5, 2, 4, 3, 6] 모두 가능한 결과입니다.

2. **사이클 감지**: 위상 정렬은 사이클이 없는 방향 그래프(DAG)에서만 가능합니다. 만약 그래프에 사이클이 있다면, 모든 노드를 처리했을 때도 진입차수가 0이 되지 않는 노드가 남게 됩니다.

3. **적용 제한**: 무방향 그래프에서는 위상 정렬을 적용할 수 없습니다. 방향성이 있는 그래프에서만 적용 가능합니다.

4. **시간 복잡도**: 위상 정렬의 시간 복잡도는 O(V+E)입니다. 여기서 V는 노드의 수, E는 간선의 수입니다. 모든 노드와 간선을 한 번씩 확인하기 때문입니다.

## 위상 정렬 파이썬 구현

다음은 위상 정렬을 파이썬으로 구현한 코드입니다:

```python
from collections import deque

# 노드의 개수와 간선의 개수를 입력받기
v, e = map(int, input().split())
# 모든 노드에 대한 진입차수는 0으로 초기화
indegree = [0] * (v + 1)
# 각 노드에 연결된 간선 정보를 담기 위한 연결 리스트(그래프) 초기화
graph = [[] for i in range(v + 1)]

# 방향 그래프의 모든 간선 정보를 입력받기
for _ in range(e):
    a, b = map(int, input().split())
    graph[a].append(b)  # 정점 A에서 B로 이동 가능
    # 진입차수를 1 증가
    indegree[b] += 1

# 위상 정렬 함수
def topology_sort():
    result = []  # 알고리즘 수행 결과를 담을 리스트
    q = deque()  # 큐 기능을 위한 deque 라이브러리 사용

    # 처음 시작할 때는 진입차수가 0인 노드를 큐에 삽입
    for i in range(1, v + 1):
        if indegree[i] == 0:
            q.append(i)

    # 큐가 빌 때까지 반복
    while q:
        # 큐에서 원소 꺼내기
        now = q.popleft()
        result.append(now)
        # 해당 원소와 연결된 노드들의 진입차수에서 1 빼기
        for i in graph[now]:
            indegree[i] -= 1
            # 새롭게 진입차수가 0이 되는 노드를 큐에 삽입
            if indegree[i] == 0:
                q.append(i)

    # 위상 정렬을 수행한 결과 출력
    for i in result:
        print(i, end=' ')

topology_sort()
```

### 코드 설명:

1. **진입차수 초기화**: 모든 노드의 진입차수를 0으로 초기화합니다.
2. **그래프 구성**: 방향 그래프의 간선 정보를 입력받아 그래프를 구성하고, 각 노드의 진입차수를 계산합니다.
3. **큐 초기화**: 진입차수가 0인 노드를 모두 큐에 넣습니다.
4. **위상 정렬 수행**: 
   - 큐에서 노드를 꺼내 결과 리스트에 추가합니다.
   - 해당 노드에서 나가는 모든 간선을 제거하고, 이로 인해 진입차수가 0이 된 노드를 큐에 추가합니다.
   - 큐가 빌 때까지 이 과정을 반복합니다.
5. **결과 출력**: 위상 정렬 결과를 출력합니다.

## 위상 정렬의 응용

위상 정렬은 다양한 실제 문제에 응용할 수 있습니다:

1. **빌드 시스템**: 소프트웨어 빌드 시스템에서 라이브러리나 모듈 간의 의존 관계를 고려한 컴파일 순서를 정할 때
2. **일정 계획**: 작업 간 의존 관계가 있는 프로젝트의 일정을 계획할 때
3. **선수 과목 계획**: 대학의 학습 과정에서 선수 과목을 고려한 수강 계획을 세울 때
4. **패키지 의존성 관리**: 소프트웨어 패키지 간의 의존성을 관리할 때

## 위상 정렬 결론

위상 정렬은 방향성 비순환 그래프(DAG)에서 노드들의 선행 관계를 지키면서 일렬로 나열하는 알고리즘입니다. 선수 과목 계획, 작업 스케줄링, 소프트웨어 패키지 빌드 순서 등 순서가 중요한 다양한 실생활 문제에 적용할 수 있습니다.

위상 정렬의 핵심 개념은 **진입차수**와 **그래프의 방향성**입니다. 사이클이 있는 그래프에서는 위상 정렬이 불가능하므로, 알고리즘을 적용하기 전에 그래프에 사이클이 없는지 확인하는 것이 중요합니다.

효율적인 구현을 위해서는 큐 자료구조를 활용하여 진입차수가 0인 노드를 순서대로 처리하는 방법이 가장 많이 사용됩니다. 이 방법을 통해 O(V+E)의 시간 복잡도로 위상 정렬을 수행할 수 있습니다.
